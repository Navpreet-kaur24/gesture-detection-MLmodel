# Machine Learning Model Exploration 🤖

## Task 3 — InAmigos Foundation

This project is a beginner-friendly Machine Learning experiment created using **Google Teachable Machine**.

The objective was to gain hands-on experience with training and testing a Machine Learning model without requiring advanced programming.

## 🎯 Objective

To understand how a Machine Learning model can learn patterns from examples and use those patterns to make predictions on new inputs.

## 🛠️ Tool Used

**Google Teachable Machine**

Model Type: **Image Classification**

## 🔄 ML Workflow

Examples → Training → Testing → Prediction

## 📌 Steps Performed

1. Created an Image Classification project.
2. Created different classes for the model.
3. Added example images for each class.
4. Trained the Machine Learning model.
5. Tested the trained model with new inputs.
6. Observed the model's predictions.
7. Exported the trained model.

## 📊 Results

The trained model was tested using new inputs to observe whether it could correctly identify the classes it had learned from the training examples.

Screenshots of the training and testing process are included in this repository.

## 🧠 What I Learned

- How training data is provided to a Machine Learning model.
- How a model learns patterns from examples.
- How to train and test an image classification model.
- How predictions are generated.
- Why the quality and variety of training data are important.
- How Machine Learning can be explored without advanced coding.
